# Business Requirements Document (BRD)

> **Template purpose:** Define the structure of a project-specific BRD. This Markdown file is an application-level structural reference only; the generated and stored document is a Word file (`.docx`).
>
> **Generation rules:** Preserve the section order. Use only user-provided requirements and permitted, attributable context. Do not invent business facts, approvals, SAP configuration, or metrics. Where information is unavailable, mark it `TBD` and add a corresponding entry under Open Clarifications. Do not treat a generated draft as approved.
